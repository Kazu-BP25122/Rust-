## Rust
- C,C++と同じようにメモリを直接いじることができ、メモリ安全性が高い言語(malloc()やfree()をしなくていい)。
- 安心安全で超高速。
- やろうとすればunsafeで生のメモリを触れる -> OSを作れる。

## cargo
- Rustのバージョンやビルド環境を整理してくれる
- cargo new プロジェクト名でプロジェクトファイルを作成
- cargo runで実行

## 基本事項
- Cと同じように末尾に;

## 変数
- let x = 3;　のように宣言する。宣言後は変えられない。
- let mnt x = 3;　のようにmntを挟むと後から変えられる。
- Rustには型推論機能が付いているので、明記しなくても良い。
- 型を明示する場合は、let x:i32 = 3;　のように「変数名:型」の順で書く。

## 配列
### 固定長配列
- let a = [1,2,3];　のように宣言する。
- 型宣言をする場合は let a: [型; 要素数] = [1,2,3];　のように書く。
- 変数と同じようにmntを挟むと要素の書き換えができる。
### 可変長配列
- let a = vec![1,2,3];　のように宣言する。
- a.push(値);　で要素を末尾に追加でき、a.pop();　で末尾の要素を取り出して削除できる。(スタックみたいに使える)
- let mnt 配列名: Vec<型> = Vec::new();　で空の可変長配列を作成できる。

## 出力
- println!()　でターミナルに出力。末尾は自動改行される。print!()にすると改行されない。
- 変数を出力する場合は　println!("x = {}", x);　のように書く。

## 関数
- fn 関数名(引数1, 引数2, ...) -> 返り値の型 {} で定義する。
- return は不要で、返り値には;を付けない。
